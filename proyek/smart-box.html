TUGAS AKHIR

Rancang Bangun Smart Box Berbasis IoT dengan Autentikasi Face Recognition untuk Sistem Penerimaan Paket Otomatis

Sistem penerimaan paket otomatis untuk lingkungan indekos dengan autentikasi penghuni dan akses kurir.

Poster Buku TA Video Demo

LATAR BELAKANG

Penerimaan paket yang lebih aman

Proses penerimaan paket di lingkungan indekos masih sering dilakukan secara manual, terutama ketika penghuni tidak berada di tempat. Kondisi ini dapat meningkatkan risiko paket hilang, tertukar, atau diambil oleh pihak yang tidak berwenang.

TUJUAN

Otomatis & mudah dipantau

Proyek ini bertujuan membangun smart box berbasis Raspberry Pi yang dapat meningkatkan keamanan dan efisiensi penerimaan paket melalui face recognition, QR Code, sensor, website, dan notifikasi Telegram.

PERANCANGAN SISTEM

Rancangan & Arsitektur Sistem

01

Use Case

Menggambarkan interaksi Admin, Penghuni, dan Kurir dalam sistem Smart Box.

Lihat detail

Kurir melakukan autentikasi menggunakan QR Code, sedangkan penghuni menggunakan pengenalan wajah. Admin berperan dalam pengelolaan sistem dan pemantauan aktivitas.

02

Blok Diagram

Menunjukkan keterkaitan perangkat input, proses, dan output pada sistem.

Lihat detail

Input dari kamera dan sensor diproses oleh Raspberry Pi sebagai pengendali utama dan diteruskan ke server untuk verifikasi, pencatatan aktivitas, serta penyimpanan database. Output berupa akses pintu, buzzer, dan notifikasi Telegram.

03

Diagram IPO

Menjelaskan alur input, proses, dan output dari sistem Smart Box.

Lihat detail

Sistem menerima data dari kamera, website, dan berbagai sensor. Data diproses oleh Raspberry Pi dan server hingga menghasilkan akses pintu, indikator buzzer, log website, serta notifikasi Telegram.

04

Flowchart

Menggambarkan alur kerja utama sistem berdasarkan mode kurir dan penghuni.

Lihat detail

Mode kurir menggunakan QR Code dan verifikasi nomor resi, sedangkan mode penghuni menggunakan InsightFace–ArcFace. Setiap proses akses dicatat dalam log dan sistem memberikan notifikasi.

05

Wiring Diagram

Menunjukkan koneksi komponen perangkat keras Smart Box berbasis Raspberry Pi 4.

Lihat detail

Raspberry Pi 4 terhubung dengan webcam, sensor ultrasonik, sensor getar, push button, buzzer, relay, dan solenoid door lock beserta sistem catu dayanya.

06

ERD Database

Menggambarkan hubungan data pengguna, penghuni, paket, dan aktivitas sistem.

Lihat detail

Struktur database terdiri dari users, penghuni, pakets, dan activity_logs untuk mengelola data pengguna, paket, serta riwayat aktivitas Smart Box.
