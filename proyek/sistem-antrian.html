PROJECT PRIBADI

Sistem Antrian Klinik

Sistem antrean berbasis web yang memungkinkan pasien memantau antrean dan petugas mengelola pemanggilan serta recall nomor antrean.

Halaman Pasien → Halaman Petugas → GitHub →

LATAR BELAKANG

Antrean yang lebih fleksibel

Ide sistem ini muncul dari pengalaman pribadi saat menunggu antrean di klinik. Dari pengalaman tersebut, saya berpikir bahwa akan lebih praktis jika pasien dapat mengetahui perkembangan antrean tanpa harus terus menunggu di tempat. Karena itu, saya mencoba membuat sistem antrean berbasis web yang memungkinkan pasien memantau antrean, sementara petugas dapat mengelola pemanggilan dan recall nomor antrean.

TUJUAN

Mempermudah proses antrean

Sistem dibuat untuk mempermudah pasien dalam memantau perkembangan antrean dan mengecek nomor antrean, sekaligus membantu petugas mengelola pemanggilan nomor secara langsung, termasuk melewati nomor pasien yang belum hadir dan melakukan recall ketika pasien sudah kembali.

PERANCANGAN SISTEM

Rancangan Sistem

01

Flowchart

Menggambarkan alur proses antrean mulai dari nomor ditambahkan oleh petugas, pasien memantau antrean, hingga proses pemeriksaan. Jika pasien tidak hadir saat dipanggil, nomor dapat dilewati dan dilakukan recall ketika pasien sudah kembali.

02

Use Case

Menggambarkan interaksi pasien dan petugas dengan sistem dalam proses pengelolaan antrean. Pasien dapat memantau nomor antrean, sedangkan petugas mengelola pemanggilan nomor.

03

ERD Database

Menggambarkan struktur dan hubungan data yang digunakan dalam sistem untuk menyimpan informasi pengguna dan antrean.

FITUR UTAMA

Fitur Sistem Antrian

01

Monitoring Antrean

Pasien dapat memantau nomor antrean yang sedang dipanggil dan melihat perkembangan antrean melalui halaman pasien.

02

Cek Nomor Antrean

Pasien dapat mengecek nomor antrean untuk mengetahui posisi dan status antreannya melalui halaman pasien.

03

Login Petugas

Petugas melakukan login sebelum mengakses halaman untuk mengelola proses antrean.

04

Dashboard Petugas

Dashboard menampilkan informasi antrean dan menjadi halaman utama petugas dalam mengelola proses antrean.

05

Menambahkan Nomor Antrean

Petugas dapat menambahkan nomor antrean baru ke dalam sistem sebelum proses pemanggilan dilakukan.

06

Recall Nomor Antrean

Petugas dapat memanggil kembali nomor antrean yang sebelumnya dilewati ketika pasien sudah kembali.
